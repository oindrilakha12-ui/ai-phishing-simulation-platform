# Password Hygiene

Use a long, unique password for every account. A passphrase of four or more random words is easier to remember and harder to crack than a short, complex password.

A password manager generates and stores unique passwords, so you only need to remember one strong master password. It also helps against phishing: a password manager will not autofill on a look-alike domain, which is a useful warning sign.

Reusing passwords is dangerous. When one site is breached, attackers try the same email and password on other sites. This is called credential stuffing.

Change a password immediately if you typed it into a suspicious page, if a service tells you about a breach, or if you see sign-in activity you don't recognize.

Never send passwords by email or chat, and never enter them after following a link in an unexpected message. Go to the site yourself by typing the address or using a bookmark.
