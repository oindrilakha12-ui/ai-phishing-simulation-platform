# Multi-Factor Authentication (MFA)

Multi-factor authentication asks for something you know (a password) plus something you have (an authenticator app, a security key) or something you are (a fingerprint). Even if a password is stolen, the attacker still needs the second factor.

Authenticator apps and hardware security keys are stronger than SMS codes. SMS can be intercepted through SIM-swap fraud. Phishing-resistant methods such as FIDO2 security keys and passkeys bind the login to the real website, so a look-alike site cannot use them.

Never share an MFA code with anyone, including someone claiming to be IT support. Legitimate staff never need your code.

MFA fatigue (push bombing) is when an attacker who already has your password triggers repeated push prompts, hoping you approve one to make them stop. If you get a prompt you did not start, deny it and report it, then change your password.

Number matching, where you type the number shown on the login screen into your app, defeats most push-fatigue attacks.
